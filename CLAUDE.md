# Portfolio — Vincent Sotoya

Personal portfolio site positioning Vincent as a real estate virtual assistant (VA) with a full-stack
engineering background as his edge.

**Stack:** Astro + Tailwind CSS, React components only where interactivity is needed, blog via Astro
content collections (Markdown/MDX), contact form via Formspree, deploy on Vercel.

**Design direction:** modern tech-forward (dark base UI, teal/indigo accent). Full detail in
[docs/content.md](docs/content.md).

**Ground rule:** `Resume/Resume_Vincent_Sotoya_v2.pdf` is the source of truth for experience and
skills. Never invent clients, results, or tools not evidenced in the resume or explicitly given by
Vincent.
